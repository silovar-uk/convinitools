テキスト便利変換ツール v2.2

【v2.2の修正｜裏側の整理とUX基盤】
・共通設定を app-core.js に集約
  - ツールID、右クリックメニュー、保存キー、既定ツールを一元管理
  - UIとService Workerが同じ定義を参照するため、追加・削除時の食い違いを減らしました

・保存先をChrome拡張向けに整理
  - 最後に使ったツールは chrome.storage.local へ移行
  - 旧 localStorage の値は初回だけ自動移行
  - 右クリック連携は chrome.storage.session に変更し、60秒で失効
  - 再起動後に古い選択テキストが突然出る事故を防ぎます

・右クリック連携を実態に合わせて再設計
  - 「改行修正」「全角→半角変換」に限定
  - プレーンテキストしか渡せない右クリック経路から、意味の薄かったMD変換を撤去

・タブ操作を標準化
  - role / aria-selected / aria-controls を追加
  - ← → Home End キーでタブ移動可能
  - キーボード利用時だけ明確なフォーカス表示

・表示と実装を分離
  - HTML内のインラインstyleを撤去
  - 外部Google Fonts依存を撤去し、OS標準フォントへ
  - 動きを減らすOS設定（prefers-reduced-motion）にも対応

・自動検証を追加
  - npm run verify でManifest、タブとパネルの対応、重複ID、廃止済みレッズ検索の残骸、
    inline style、保存方式などを一括チェックできます

【v2.1の修正｜専用検索の撤廃とサイドパネルUX整理】
・旧・クラブ専用検索機能を完全撤廃
  - 専用タブ、検索フォーム、日付指定、Googleサイト内検索、X公式ポスト検索を削除
  - 特定サイト／特定SNSアカウントへの固定検索ロジックも削除
  - Manifest、README、CSS内の関連文言・テーマ定義も削除

・初期表示を「定型メール作成」に変更
  - 専用検索削除後も、空表示や選択不能が起きない構造に整理

・最後に使ったツールを次回も復元
  - サイドパネルを閉じても、次に開いたとき直前の機能へ戻ります
  - 旧版で保存された廃止済みタブIDが残っていても、自動的に定型メール作成へフォールバックします

・タブの視覚ノイズを低減
  - 未選択タブは白基調に統一
  - 機能ごとの色は選択中・ホバー時を中心に使用
  - 「全部が主張する」状態から「今使っているものが分かる」状態へ変更

【v2.0の修正｜調整カレンダー】
・横方向の複数日一括反映を削除
  - 週表示は、同じ日の列を上から下へドラッグする操作だけに統一
  - 誤って別の日まで選ぶことがなくなりました

・日付ごとの「条件カード」へ刷新
  - 選択後、下に日付順で条件カードを表示
  - 「編集」から、時間帯／以降／終日／午前／午後／夜／時間未定を切り替え可能
  - 時間、メモ（例：オンライン可）も後から変更できます
  - 日付順は、編集しても固定です

・月表示で、日付だけの条件を追加
  - 時間未定、終日、午前、午後、夜を選んで日付をクリック
  - 例：7/20(日) 時間未定

・出力を用途別に切替
  - 箇条書き（・）
  - チャット向け（先頭記号なし）
  - 省略（曜日は括弧なし）
  - 同じ条件・同じメモの連続日程だけを、出力時にまとめます

・重複と削除の安全性を追加
  - 同じ日の時間条件が重なる場合は、カードと一覧で注意表示
  - 削除後7秒間は「元に戻す」が表示されます
  - 「直前を戻す」も利用できます

【カレンダーの使い方】
1. 時間を指定する場合は「週表示」を開く
2. 「時間帯」または「以降」を選び、同じ日の列を縦にクリック／ドラッグ
3. 日付だけの候補は「月表示」で種別を選び、日付をクリック
4. 下の条件カードで必要に応じて編集
5. 出力形式を選び、コピー

【v1.9以前からの主な機能】
・曜日入り、時間幅、以降表記
・SJIS／UTF-8向けのMD変換と文字整形
・改行修正、全半角、HTMLタグ除去、乱文字生成

【導入】
1. ZIPを解凍する
2. Chromeで chrome://extensions を開く
3. デベロッパーモードをONにする
4. 「パッケージ化されていない拡張機能を読み込む」を押す
5. 解凍した convinitools フォルダを選ぶ

既存版を上書きする場合は、フォルダ内のファイルを差し替え後、
chrome://extensions で対象拡張機能の更新ボタンを押してください。
