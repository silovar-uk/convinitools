テキスト便利変換ツール v2.0

【v2.0の修正｜調整カレンダー】
・横方向の複数日一括反映を削除
  - 週表示は、同じ日の列を上から下へドラッグする操作だけに統一
  - 誤って別の日まで選ぶことがなくなりました

・日付ごとの「条件カード」へ刷新
  - 選択後、下に日付順で条件カードを表示
  - 「編集」から、時間帯／以降／終日／午前／午後／夜／時間未定を切り替え可能
  - 時間、メモ（例：オンライン可）も後から変更できます
  - 日付順は、編集しても固定です

・月表示で、日付だけの条件を追加
  - 時間未定、終日、午前、午後、夜を選んで日付をクリック
  - 例：7/20(日) 時間未定

・出力を用途別に切替
  - 箇条書き（・）
  - チャット向け（先頭記号なし）
  - 省略（曜日は括弧なし）
  - 同じ条件・同じメモの連続日程だけを、出力時にまとめます

・重複と削除の安全性を追加
  - 同じ日の時間条件が重なる場合は、カードと一覧で注意表示
  - 削除後7秒間は「元に戻す」が表示されます
  - 「直前を戻す」も利用できます

【カレンダーの使い方】
1. 時間を指定する場合は「週表示」を開く
2. 「時間帯」または「以降」を選び、同じ日の列を縦にクリック／ドラッグ
3. 日付だけの候補は「月表示」で種別を選び、日付をクリック
4. 下の条件カードで必要に応じて編集
5. 出力形式を選び、コピー

【v1.9以前からの主な機能】
・曜日入り、時間幅、以降表記
・SJIS／UTF-8向けのMD変換と文字整形
・改行修正、全半角、HTMLタグ除去、レッズ検索、乱文字生成

【導入】
1. ZIPを解凍する
2. Chromeで chrome://extensions を開く
3. デベロッパーモードをONにする
4. 「パッケージ化されていない拡張機能を読み込む」を押す
5. 解凍した text-converter-calendar-v2.0 フォルダを選ぶ

既存版を上書きする場合は、フォルダ内のファイルを差し替え後、
chrome://extensions で対象拡張機能の更新ボタンを押してください。
